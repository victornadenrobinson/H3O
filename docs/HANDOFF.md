## Goal
Decide whether fine-tuned GRACE-2L-SMAX-OMAT-medium potentials give reliable H solubility / mixing results in superionic H2O (300-700 GPa, 3000-9000 K), then move to liquid/fluid hulls and melting. Method: dG = mu_H(host) - mu_H(pure H) from proxy-guided Widom/deletion + BAR (PWidom), cross-checked by TDI/Frenkel-Ladd free energies and DFT single points. The user works on Perlmutter (checkout ~/work/H3O, branch `gpt/perlmutter-pwidom`, 4x A100-40GB interactive jobs, 2 h limit; CPU DFT via `dgcheck_jobs.sh`). The assistant has NO access to Perlmutter: it writes/pushes code, the user runs it and pastes output. Files reach the user by `git fetch origin claude/youthful-brown-4qfaeg; git show FETCH_HEAD:<path> > <path>` (plain `git pull` fails: local edits there).

## Key conventions and cautions
- dG per added H includes the ideal-dilution term, pressure and finite-size corrections; single-H insertion is only meaningful in the atomic fluid (use `mol_frac`).
- Thermostat bug history: friction 0.01 (~1 ps) vs 100 fs; frames caches store md_settings; mixing old/new results is a trap.
- Gamma-only labels are fine for insulating molecular cells with edges >= ~8 A; k-point bias ~ -53 meV/H in H-rich cells.
- User preferences: foreground in-place dashboards (no screen clear), informative output, quick runs, liquids over solids, no H2-PWidom yet.
